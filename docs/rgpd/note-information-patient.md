# Note d'information individuelle (document RGPD n° 3)

> À remettre au patient (ou à son représentant) lors de l'inclusion dans le recueil.

Madame, Monsieur,

Votre infirmier·e utilise un outil professionnel qui regroupe la cotation des soins,
les transmissions entre soignants et un recueil de données de suivi (constantes,
dépistage ICOPE, suivi de plaies).

**Ce que nous enregistrons** : vos initiales, votre année de naissance, votre commune,
votre situation (vivez-vous seul·e, présence d'un aidant), vos pathologies principales,
et les observations liées à chaque passage de soins.

**Ce que nous n'enregistrons pas** : aucune photographie n'est stockée dans l'outil ;
les informations pratiques (code de portail, etc.) ne sortent jamais de l'appareil.

**Exploitation pour la recherche** : vos données peuvent être analysées sous un code
(ex. P014) qui ne permet pas de vous identifier, dans le cadre de la méthodologie de
référence **MR-004** de la CNIL. Vous pouvez vous y opposer à tout moment sans aucune
conséquence sur vos soins.
